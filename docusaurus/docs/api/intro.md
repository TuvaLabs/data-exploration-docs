# API Reference

Welcome to the Data Exploration API documentation. This section provides detailed information about the library's components, utilities, and configuration options.

## Core Components

The Data Exploration library consists of several key components:

- **Components**: Reusable UI components for data visualization
- **Containers**: Layout and container components
- **Utils**: Utility functions and helpers
- **Lib**: Core library functionality

## Getting Started

To use the Data Exploration library in your project:

```bash
npm install @tuvalabs/data-exploration
```

Then import the components you need:

```javascript
import { DataExplorer, Chart } from '@tuvalabs/data-exploration';
```

## Component Categories

### Visualization Components
- Charts and graphs
- Data tables
- Interactive visualizations

### Layout Components
- Containers
- Grids
- Responsive layouts

### Utility Functions
- Data processing
- Formatting
- Validation

## Configuration

The library can be configured through various options:

};
